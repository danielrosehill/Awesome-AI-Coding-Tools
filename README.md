# Awesome AI Coding Tools

Generated: September 1, 2025

A point in time snapshot of AI coding tools and agents for those starting, or continuing, an exploration of this software category.

Note: the long tail of CLIs (especially) is a vast one. This is a very partial selection but is intended to provide a map of the main areas of activity rather than be any kind of exhaustive list.
